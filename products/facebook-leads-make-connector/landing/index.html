transform what changes

Every form, one shape.

Facebook gives every Instant Form a different field layout — standard questions keep a stable name, but custom questions are slugged from whatever the form's author typed. Make's native module maps fields per scenario, so a Page with several forms either needs several scenarios or silently drops what it wasn't built for.

faq before you buy

Questions worth answering upfront.

Do I need to know Python to use this?

No — deploying is following the setup guide's commands. Reading the code is only needed if you want to change the field-mapping rules yourself.

Does this replace Make.com?

No. It replaces the fragile part — talking to Facebook — and hands Make one clean payload. Your existing Airtable, Outlook, or Gmail modules stay in Make.

What if my form has fields this doesn't recognize?

Anything unmatched lands in a custom_fields object instead of being dropped, so you can still see it and map it manually if you want it structured later.
